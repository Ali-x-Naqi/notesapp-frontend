# notesapp-frontend

Frontend for the NotesApp — built during the Arbisoft Web Internship 2026.

**Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS 4

**Backend:** [notesapp-backend](https://github.com/Ali-x-Naqi/notesapp-backend) (Django + PostgreSQL)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment Variables

```
NEXT_PUBLIC_API_URL=http://localhost:8000
```
